# Database DynamoDB files

This folder contains the CSV files used to represent the DynamoDB data model for the Intelligent Academic Path Optimizer (IAPO) project. Each CSV matches a DynamoDB table  contains data(items) used for database design and testing.

The folder contains CSV representations of the following DynamoDB entities:
- Department
- Major
- Student
- Course
- Semester
- Courses Offered
- Major Course
- Degree Requirements
- Prerequisites
- Student Constraints
- Student Schedule

Detailed descriptions of each file, including attributes are provided in the Data Dictionary.
